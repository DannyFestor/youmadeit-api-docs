## Agent skills

### Issue tracker

Issues about the published contract and its rendered page live as GitHub issues in this repo; issues about the contract's content go to youmadeit-app, which generates `openapi.json`, and product-wide and cross-repo issues live in the parent. See `docs/agents/issue-tracker.md`.

### Triage labels

The five canonical triage labels use the default names: `needs-triage`, `needs-info`, `ready-for-agent`, `ready-for-human`, `wontfix`. See `docs/agents/triage-labels.md`.

### Domain docs

The glossary is the parent's `GLOSSARY.md`. Decisions inside this repo are in its own `docs/adr/`, numbered from 0400; decisions that cross repos are in the parent's. See `docs/agents/domain.md`.
