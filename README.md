# You Made It — API docs

The published OpenAPI contract of the You Made It API and its rendered reference.

- `openapi.json` is generated by [youmadeit-app](https://github.com/DannyFestor/youmadeit-app); never edit it by hand.
- `index.html` is a self-contained [Scalar](https://scalar.com) page with the contract inlined. Regenerate it after the contract changes:

  ```bash
  node generate.mjs
  ```

Releases will be semver tags, with a major bump for any breaking change; the Android and iOS clients pin them ([ADR-0016](https://github.com/DannyFestor/youmadeit/blob/main/docs/adr/0016-standalone-contract-generator-and-published-contract.md)).
